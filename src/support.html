Support

DMARC Shield is a free community project. Help is available through GitHub.

Install

From Microsoft Marketplace

In Outlook, open Apps (or Get Add-ins), search for DMARC Shield and choose Add.

For your whole organisation (administrators)

In the Microsoft 365 admin center, go to Settings → Integrated apps → Upload custom apps, choose Office Add-in, and provide the manifest URL https://berndverhofstadt.github.io/dmarc-shield/manifest.xml.

Just for you (sideloading)

  1. Download manifest.xml (also attached to every GitHub release).
  2. Open aka.ms/olksideload in Outlook on the web.
  3. Choose My add-ins → Custom add-ins → Add a custom add-in → Add from file and select the manifest.

Using it

  1. Open a message and choose Apps → DMARC Shield → Check sender.
  2. Pin the pane to check every message you select automatically (Microsoft 365 work and school accounts).
  3. Expand What does this mean? for an explanation of each result.

Frequently asked questions

Why is a Microsoft 365 message blue instead of green?

Exchange Online doesn't write the sender's DMARC policy into the headers. Without it, DMARC Shield can't claim the domain rejects fakes. Use Look up policy (or enable automatic lookups in the settings) to fetch the policy from DNS.

Why is mail from a gmail.com or outlook.com address blue?

Those domains publish a DMARC policy of p=none (monitor only), so a forged gmail.com sender isn't rejected everywhere. DMARC Shield reports this honestly.

Why is a brand logo blue when the company has a certificate?

Some certificate hosts (for example DigiCert's vmc.digicert.com) don't allow add-ins running in a browser to download the certificate. DMARC Shield then can't verify it and honestly shows blue. Mail providers that support BIMI themselves don't have this limitation; Microsoft doesn't support BIMI.

Does it work on my phone?

No. Outlook for iOS and Android don't allow add-ins to read message headers (Microsoft Mailbox API 1.8), so DMARC Shield is not offered there.

Why doesn't it run automatically?

Outlook only starts add-ins when you open them. Pinning the pane is the closest to automatic that Outlook currently allows.

Is my email sent anywhere?

No. See the privacy policy.

Report a problem

Open an issue at github.com/berndverhofstadt/dmarc-shield/issues. Mention your Outlook version and the result you expected. If a result looks wrong, the message's Authentication-Results headers help a lot. Remove anything private first. Never post full messages.

Security issues

Please report vulnerabilities privately via GitHub security advisories, not in public issues.
